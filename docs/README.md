## Documentation Rules

- Keep the root `README.md` concise and link here for detailed material.
- Place new documentation in the narrowest matching category.
- Use lowercase kebab-case file names.
- Update links whenever a document moves.
- Mark historical snapshots clearly instead of silently rewriting past findings.
- Keep implementation status aligned with the current codebase.
