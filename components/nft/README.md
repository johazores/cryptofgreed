# Legacy NFT Components

This folder contains presentation code from the original NFT prototype.

## Status

- NFT custody is disabled.
- NFT management is not part of the active game interface.
- Ordinary equipment no longer requires NFT identifiers.
- Steam and console product plans are fully off-chain.

Do not build new gameplay, progression, economy, or account behavior on these components.

The remaining files are retained temporarily for migration review. Remove or archive them after legacy data handling is complete and dependency checks confirm that the active product no longer requires them.
