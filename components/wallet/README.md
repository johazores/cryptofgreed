# Legacy Wallet Components

This folder contains UI from the original wallet and NFT prototype.

## Status

- Custodial wallet creation is disabled.
- Active navigation does not expose wallet features.
- NFT custody endpoints are disabled.
- These components are not part of the current premium game direction.

Do not add new product features here and do not import these components into active gameplay or account screens.

The remaining files are retained temporarily for migration review. They should be archived or removed after legacy data handling is complete and a clean production build confirms that no active dependency remains.
